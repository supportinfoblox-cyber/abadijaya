1. Ringkasan Sistem & Cara Kerja Sinkronisasi Cloud

Aplikasi TicketOps dirancang dengan arsitektur cloud terpusat. Basis data tiket berada di Supabase Cloud, antarmuka web dipublikasikan melalui Cloudflare Pages, dan penarikan data iCare OTRS dijalankan secara otomatis oleh background daemon.

Alur Aliran Data Tiket:

🏢 Portal iCare OTRS ➔ ⚙️ Background Sync Daemon (di Docker / Termux HP)
➔ ☁️ Supabase Cloud DB ➔ 📱 Pengguna (Web Cloudflare / HP Android)
Pertanyaan Kritis: Apakah laptop boleh dimatikan total?
YA, BOLEH DIMATIKAN! Jika background daemon dijalankan di Termux HP Android atau Server Docker Cloud, maka mesin tersebutlah yang bekerja menarik tiket setiap 3 menit. Laptop Anda bebas dimatikan kapan saja, dan tiket baru akan tetap terus masuk ke Supabase!

2. Panduan Penggunaan di HP Android (Tanpa Install Apapun)

Aplikasi TicketOps sudah dilengkapi dengan fitur Progressive Web App (PWA) dan antarmuka responsif ramah layar sentuh (resolusi smartphone):

  1. Buka browser Google Chrome di HP Android Anda.
  2. Akses alamat web aplikasi: https://ticketops.pages.dev
  3. Tekan tombol menu titik tiga (⋮) di pojok kanan atas Chrome.
  4. Pilih menu "Tambahkan ke Layar Utama" (atau "Instal Aplikasi").
  5. Ikon TicketOps akan muncul di layar beranda (Homescreen) HP Anda layaknya aplikasi Android bawaan (native), beroperasi fullscreen tanpa bilah URL browser.

3. Panduan Menjalankan Penarik Tiket di Termux (HP Android)

Dengan cara ini, HP Android Anda bertindak sebagai server penarik tiket 24 jam, sehingga Anda tidak perlu lagi menyalakan laptop atau mengetik perintah apapun di laptop.

Langkah 1: Setup Sekali Saja di Termux (1-Klik)

Buka aplikasi Termux di HP, lalu copy-paste perintah berikut dan tekan Enter:

pkg update -y && pkg install -y git nodejs-lts python curl && \
pip install requests urllib3 && \
git clone https://github.com/supportinfoblox-cyber/abadijaya.git ~/ticketops && \
cd ~/ticketops && npm install --production

Langkah 2: Menjalankan Background Sync Daemon

Untuk memulai penarikan tiket iCare otomatis setiap 3 menit di HP:

cd ~/ticketops
bash scripts/start_sync_daemon.sh

Langkah 3: Mencegah Termux Dimatikan oleh Penghemat Baterai Android

Agar Android tidak mematikan Termux saat layar HP padam:

termux-wake-lock

(Atau tarik bilah notifikasi atas HP Anda, pada notifikasi Termux klik tombol "Acquire Wakelock").

Apa yang terjadi jika HP kehabisan baterai / restart?
Semua instalasi tetap tersimpan aman. Saat HP hidup kembali, Anda TIDAK PERLU INSTALL ULANG. Cukup buka Termux lalu ketik:
cd ~/ticketops && bash scripts/start_sync_daemon.sh

Tips Otomatis: Membuat Shortcut 1 Kata di Termux

Jalankan perintah ini sekali di Termux agar Anda cukup mengetik tarik untuk menjalankan daemon:

echo "alias tarik='cd ~/ticketops && bash scripts/start_sync_daemon.sh'" >> ~/.bashrc
echo "alias status='ps aux | grep sync'" >> ~/.bashrc
source ~/.bashrc
  • Ketik tarik: Otomatis masuk folder dan menyalakan penarik tiket.
  • Ketik status: Memeriksa apakah penarik tiket sedang berjalan di latar belakang HP.

4. Panduan Menjalankan Docker Container (Docker Hub)

Image resmi telah diupload dan siap digunakan langsung dari registry Docker Hub:

Nama Image: centerback/ticketops:latest

A. Menjalankan di Server / Komputer Lain (Cukup 1 Baris):

docker run -d -p 8080:8080 --name ticketops-app centerback/ticketops:latest

B. Menjalankan Menggunakan Docker Compose:

cd "/home/ismail/Downloads/Project Lainnya/Project Lain 1"
docker compose up -d
Fitur Otomatis di Container Terbaru:
Di dalam image centerback/ticketops:latest, skrip docker-entrypoint.sh otomatis menjalankan:
1. Background Sync Daemon (Node.js & Python) setiap 3 menit.
2. Web server produksi Vite Preview di port 8080.
Anda tidak perlu lagi menjalankan skrip manual di dalam container!

6. Prosedur Kerja Sehari-hari (Rekomendasi Terbaik)

  1. Di Pagi Hari: Pastikan Termux di HP Anda aktif (atau container Docker di server menyala). Cukup ketik tarik di Termux jika HP baru dinyalakan.
  2. Sepanjang Hari: Anda dan seluruh staf tim Infoblox/BSI dapat memantau, memeriksa, mengekspor laporan CSV, dan menutup tiket langsung dari browser atau aplikasi HP di alamat https://ticketops.pages.dev.
  3. Laptop Anda: Bebas dimatikan atau digunakan untuk keperluan lain. Data tiket akan selalu segar dan up-to-date secara otomatis!
